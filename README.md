# Mark X OBD

Своё Android-приложение для диагностики Toyota Mark X 2005 (4GR-FSE) через адаптер ELM327 (Vgate / V-LINK).
Без ограничений бесплатных версий: все параметры, графики, запись поездок.

## Возможности

- Подключение к адаптеру по классическому Bluetooth (V-LINK) или BLE — пробует оба.
- Живые показатели: температура ОЖ, напряжение ЭБУ и адаптера, обороты, скорость, нагрузка, коррекции топлива по обоим банкам, MAF, дроссель, угол опережения, давление топлива, лямбда-датчики и т.д. Показываются только те, что поддерживает ЭБУ.
- Графики любого числа параметров за 2/5/10/30 минут.
- Предупреждение о перегреве: ОЖ ≥ 105 °C — красная плашка и звуковой сигнал.
- Определение вероятного включения вентиляторов по просадке напряжения, метки на графике.
- Ошибки: чтение сохранённых, ожидающих и постоянных кодов, описания на русском, стоп-кадр, стирание.
- Запись поездки в CSV с отправкой через «Поделиться» и автоматической сводкой: макс. температура, минуты выше 100 °C, вентиляторы, напряжение, пробег.
- Работа в фоне: связь и запись продолжаются при выключенном экране, в уведомлении — температура и напряжение, отдельное уведомление о перегреве.
- Автоподключение при запуске и при обрыве связи, автозапись после подключения.
- Тест аккумулятора при запуске: напряжение покоя, минимум при прокрутке стартером, зарядка генератора — с выводом.
- Тест прогрева на холостых: момент открытия термостата, температура включения вентиляторов, максимум — с выводом.
- Исследование расширенных данных Toyota (Mode 21/22, информация о блоке) и терминал для ручных команд. Только чтение.
- Журнал обмена с адаптером для отладки.
- Расход топлива (л/ч, л/100 км) по MAF, а если блок его не отдаёт — по нагрузке и оборотам; пробег, литры и стоимость текущей поездки.
- Стиль вождения в сводке: резкие разгоны и торможения, время выше 4000 об/мин, баллы 0–100; холостые на прогретом двигателе.
- Замер разгона 0–60 и 0–100 км/ч с голосовым результатом и историей.
- Пропуски зажигания по цилиндрам (Mode 06, если блок отдаёт).
- Проверка новых кодов ошибок при каждом подключении — голос, плашка и метка в записи.
- Тренды по всем поездкам: макс. температура, мин. напряжение, расход, холостые, стиль.
- Карта поездки (OpenStreetMap) с цветом линии по температуре ОЖ и метками.
- Виджет на рабочий стол: температура и напряжение.
- Настраиваемые пороги: перегрев, предупреждение, напряжение зарядки, обороты, цена бензина.
- Ночная тема в режиме «В дороге».

## Установка

1. Открыть [Releases](../../releases/latest) на телефоне (нужно быть залогиненным в GitHub, если репозиторий приватный).
2. Скачать файл `mark-x-obd-N.apk` и установить. Android попросит разрешить установку из этого источника.
3. Новые сборки ставятся поверх старых — все подписаны одним ключом.

## Использование

1. Спарить адаптер в настройках Bluetooth телефона (V-LINK, PIN 1234 или 0000).
2. Включить зажигание, открыть приложение, вкладка «Связь» → выбрать адаптер.
3. На вкладке «Датчики» нажатием на плитку добавить параметр в «Графики».
4. Для записи поездки — кнопка «● Запись».

## Сборка

APK собирается автоматически GitHub Actions при каждом пуше в `main` и публикуется в Releases.
Локально: Android Studio или `gradle :app:assembleRelease` (JDK 17, Gradle 8.9).

Ключ подписи `app/signing/shared.keystore` лежит в репозитории намеренно — это личный проект,
ключ нужен только для того, чтобы обновления ставились без удаления приложения.
